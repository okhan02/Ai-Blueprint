# AI Blueprint

A modern, responsive React application built with Vite, featuring a beautiful UI and interactive components. This project showcases various web development technologies and best practices.

## 🚀 Features

- **Modern Tech Stack**

  - React 18 with Vite
  - TypeScript support
  - Tailwind CSS for styling
  - Radix UI components
  - React Router for navigation

- **Interactive Components**

  - Animated hero section
  - Responsive navigation
  - Project showcase
  - About section
  - Contact form
  - Tools showcase
  - Footer

- **UI/UX Features**
  - Modern and clean design
  - Responsive layout
  - Smooth animations
  - Interactive elements
  - Dark mode support

## 🛠️ Technologies Used

- **Frontend Framework**

  - React 18
  - Vite
  - React Router DOM

- **Styling**

  - Tailwind CSS
  - Tailwind Animate
  - Class Variance Authority

- **UI Components**

  - Radix UI
  - Lucide React Icons
  - Embla Carousel
  - React Hook Form
  - Zod for validation

- **Development Tools**
  - ESLint
  - PostCSS
  - Autoprefixer

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository

```bash
git clone https://github.com/okhan02/Ai-Blueprint.git
cd Ai-Blueprint
```

2. Install dependencies

```bash
npm install
# or
yarn install
```

3. Start the development server

```bash
npm run dev
# or
yarn dev
```

4. Build for production

```bash
npm run build
# or
yarn build
```

## 📝 Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run build:dev` - Build for development
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build
